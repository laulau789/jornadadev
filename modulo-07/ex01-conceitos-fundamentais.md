#Exercício 1 - Conceitos fundamentais

**a. Qual é a função do AppServer?**
Resposta: O AppServer é responsável por executar o Protheus. Ele recebe os comandos enviados pelo SmartClient, processa as regras de negócio e realiza a comunicação com o banco de dados e outros serviços do sistema.

**b. O que é o RPO?**
Resposta: O RPO é o local onde o Protheus guarda os programas compilados, permitindo que o AppServer os encontre e execute quando o usuário utiliza uma rotina do sistema.

**c. Para que serve o Configurador (SIGACFG)?**
Resposta: O SIGACFG serve para configurar e administrar o ambiente Protheus, permitindo gerenciar tabelas, campos, índices e outras definições do dicionário de dados do sistema.

**d. Qual a diferença entre campo Real e campo Virtual no SX3?**
Resposta: Campo Real é gravado fisicamente na tabela do banco de dados. Campo Virtual não é gravado, seu valor é calculado em tempo de execução pelo sistema conforme uma regra ou expressão configurada.
